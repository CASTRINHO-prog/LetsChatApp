# LetsChatApp
Aplicação de mensagens LetsChatApp
LETSCHATAPP

Aplicação de mensagens, Bíblia Sagrada e armazenamento de ficheiros.

O LETSCHATAPP é um projecto de aplicação móvel Android desenvolvido com Expo, React Native, TypeScript e Firebase.

1. Planos de utilização

Plano| Preço
FREE BASIC| 0 MZN/mês
PRO| 5 MZN/mês

Bíblia Sagrada — Almeida Corrigida Fiel (ACF)

A Bíblia Sagrada ACF está desbloqueada para todos os utilizadores, incluindo:

- FREE BASIC
- PRO

O acesso à Bíblia ACF não é exclusivo do plano PRO.

2. Registo e autenticação

A política da primeira versão estabelece:

- Registo exclusivamente por número de telefone.
- Não utilizar e-mail para registo ou início de sessão.
- Verificação por SMS opcional na primeira versão.
- Possibilidade de criar conta sem confirmar o número por SMS.
- Firebase como fornecedor de autenticação por SMS.

A verificação obrigatória por SMS poderá ser introduzida numa versão futura, mediante confirmação.

3. Conversas e contactos

- Conversas privadas iniciadas através dos contactos do telefone.
- Solicitar autorização para aceder à lista de contactos.
- Identificar contactos que já utilizam o LETSCHATAPP através dos números registados.
- Permitir convidar contactos que ainda não utilizam a aplicação.
- Criação de grupos a partir dos contactos telefónicos.

4. Administração dos grupos

- Cada grupo pode ter no máximo 5 administradores.

5. Menu principal

O menu principal deve apresentar três áreas, organizadas da esquerda para a direita:

1. LETSCHAT GERAL
2. BÍBLIA SAGRADA - ACF
3. FILES SALVOS

6. Funcionalidades previstas

- Conversas privadas.
- Conversas em grupo.
- Indicador de estado online.
- Envio e recepção de mensagens.
- Conversão de voz em texto.
- Detecção do idioma.
- Conversão de texto em voz através de botão de altifalante.
- Armazenamento de ficheiros na nuvem.
- Acesso à Bíblia Sagrada ACF para todos os planos.

7. Tecnologias

- Expo
- React Native
- TypeScript
- Firebase
- Firebase Authentication
- Cloud Firestore

8. Construção da aplicação Android

O projecto pretende utilizar o Expo EAS Build para gerar um APK instalável em dispositivos Android.

A compilação deverá ser feita depois de confirmar:

- Configuração correcta do Expo.
- Dependências instaladas.
- Configuração Firebase.
- Identificador da aplicação Android.
- Configuração do perfil de compilação APK.
- Funcionamento das funcionalidades implementadas.

9. Estado do desenvolvimento

As decisões funcionais e comerciais descritas neste documento representam os requisitos do projecto.

A inclusão de uma funcionalidade neste README não significa que ela já esteja implementada ou testada. Cada funcionalidade deverá ser desenvolvida, integrada e verificada antes de ser considerada concluída.

10. Política de actualização

As alterações futuras devem respeitar as decisões confirmadas pelo proprietário do projecto.

Não reintroduzir autenticação por e-mail nem restringir a Bíblia ACF ao plano PRO.
